Stash · design refinement · Aug 30 2026 · pass 3

Grey chrome. Color only where it means something.

The card anatomy stays what shipped — hero, serif title, description, violet annotation bar, meta chips, quiet footer. Pass 3 tightens the system further: every surface that isn’t information goes grey (shadows, chips, page wash), and the spectrum fields go flat — one quiet tint per type, no gradients. Saturation lives only in the functional accents (play button, waveform) so the fields can stay calm without reading pastel. One spacing token governs the hero-to-title gap on every card. All iconography is Lucide-style vector; no emoji anywhere. Tag controls are gone from cards — grouping moves to themes.

What this asks of the code

  1. One spacing token. --card-gap (18px) between hero bottom and body top for every hero type — the production grid drifts today because each hero variant pads itself. Body side padding stays 24px; no-hero cards take 22px top.
  2. Voice-note hero. New PlayerHero in CardHero.tsx (promote the violet-waveform card from DesignCardPreview.tsx:231); rendered from ContentItemHeader.renderHero() for audio instead of no-hero + grey MediaPlayer. Waveform can be deterministic bars from a hash of the item id until real amplitudes are sampled.
  3. Spectrum fields, flat. One SpectrumField wrapper (flat tint + grain, no gradient), tints keyed by subtype at ~11% alpha; the saturated color lives in the accents (solid #544eba play button, waveform bars). All other chrome — shadows, chips, page wash — is neutral grey: color appears only where it encodes type, state, or action.
  4. Lucide everywhere, emoji nowhere. Cards, panel, toasts. The always-visible tinted type chip replaces the hover-only footer Badge.
  5. No tag UI on cards. ItemTagsManager comes off the card (tags are being retired for themes as the grouping model). The card keeps exactly: type chip, format facts, duration/pages/read-time.
  6. Subtype lives in data. Enrichment writes attributes.media.kind (voice_note | recording | music | screenshot | …); whole-blob attribute writes preserved as always.
  7. Titles are enrichment’s job for every type. Audio/video from transcript after transcribe-audio; documents by letting quick-pdf-summary’s title land; shared placeholder-title guard from analyze-image/index.ts:94. Deeply personal audio falls back to the filename per policy.
  8. Structured link enrichment grows. product (price, availability), recipe (cook time, servings, ingredients — schema.org/Recipe), place (name, hours, neighborhood), social (post text pull-quote) join linkFlavor.ts, each writing typed facts into attributes.link.* and degrading to today’s generic cover when extraction comes back empty.
  9. Video poster frames. Capture a poster at enrichment and drop the inline <video controls> chrome from the card.
