The moves

  1. Serif title, inline-editable. Card and panel finally share a voice (EditItemTitleSection is sans today). Hover shows the edit wash; no input chrome until focus.
  2. Sections are labels, not boxes. The duplicated sectionCard constant is deleted; each zone is an uppercase micro-label over a hairline. Dotted rules only inside Details.
  3. Details is a drawer, closed by default. The collapsed row still answers the common question (format · size · duration) in its summary; one tap opens filename, source, location, saved-date.
  4. Media plays here. Audio/video get the same spectrum player as the card — today the panel has no player at all.
  5. No tag editor. Tags are being retired; themes will group items. The panel loses the tags section outright rather than shipping UI we plan to remove.
  6. Color = information. Type chip and player carry the type slice; violet marks interactive; everything else is grey. All icons Lucide.
