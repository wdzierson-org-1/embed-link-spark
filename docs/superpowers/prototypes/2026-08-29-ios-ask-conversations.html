Conversations

Ask tab — conversations & sessions

Interactive prototype of the iOS port of the web's 2026-08-27/28 chat-sessions model. Everything here maps 1:1 to already-deployed backend (3h gap convention, list_conversations RPC, lazy row creation, auto-titling).

Try the flows

  1. Send a message in the fresh thread — a session row is created lazily and auto-titled from your first question (watch it appear under Today in Conversations).
  2. History pushes the Conversations list — native back bar, search pill, Today/Yesterday/This-week/month buckets, infinite scroll.
  3. Open an old conversation — pops back with it loaded (violet title pill above the thread; gap-exempt, so replies continue that session).
  4. Let go: switch to another tab while an old conversation is open, then return to Ask — the thread has cleared, and a restore banner offers one-tap reload.
  5. New chat clears the thread and forces the next send into a brand-new session (old thread stays in Conversations).
  6. 3-hour gap: use the simulator button below, then send — the stale thread clears and a new session begins, exactly like the web.
