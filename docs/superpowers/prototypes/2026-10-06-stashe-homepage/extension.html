chrome extension

Save any page in one click.

Stash it puts Stash in your toolbar. Click it to save the page you’re on; right-click to save a selection or an image. Stash reads it in the background, the same as everything else you save.

Download stash-it-extension.zip version 1.2.1, 33 KB

It isn’t on the Chrome Web Store yet, so it installs from a zip. About two minutes, in Chrome, Arc, Brave or Edge.

Install it

Six steps, once. After that it updates the same way it installed.

  1. Unzip it, and move the folder somewhere permanent

    Chrome runs the extension straight from that folder, so if you delete it later the extension stops working. Documents is a good home. Downloads is not.

  2. Open the extensions page

    Paste chrome://extensions into the address bar. A web page can’t link there, so it has to be pasted. In Chrome’s menu it’s Extensions, then Manage extensions.

  3. Turn on Developer mode

    It’s the switch in the top-right corner of that page. Three new buttons appear.

  4. Click Load unpacked and pick the folder

    Choose the stash-it-extension folder itself, the one that contains manifest.json. Stash it appears in the list, switched on.

  5. Pin it to the toolbar

    Click the puzzle-piece icon to the right of the address bar, then the pin next to Stash it.

  6. Sign in once

    Click the Stash it button. A sign-in page opens; use your Stash email and password. From then on, one click saves the page you’re on.

Three ways to save

A badge on the icon says how it went: a green check when the save landed, a red mark when it didn’t. Nothing is added to the page you’re reading.

toolbar button
Click the Stash it button

Saves the page you’re on as a link. Its title, description and text are filled in a few seconds later.

selected text
Select text, right-click, Stash it

Saves the selection as a note, line breaks and all.

an image
Right-click an image, Stash it

Saves the image itself, not just its address. Stash reads any words in it.

Good to know

  • Chrome may show a “Disable developer mode extensions” notice when it starts. Close it or choose Cancel; the extension keeps working.
  • Firefox and Safari aren’t supported. Any browser built on Chromium is fine.
  • If a save shows the red mark, click the icon to check you’re still signed in. Forgot the password? The sign-in page has a reset link.

Updating

When there’s a new version, the download above changes and its version number goes up. Download the zip again, unzip it, and replace the contents of your stash-it-extension folder. Then open chrome://extensions and click the reload arrow on the Stash it card. You stay signed in.

Removing the extension and loading it again also works, but you’ll need to sign in again.
